# Remnawave Reverse Proxy

Установщик панели управления и нод **Remnawave** с обратным прокси: Xray на порту 443 + связка с nginx (или Caddy) через Unix-сокет. Готов к работе сразу после установки — без ручной настройки инбаундов.

Сборка полностью на русском языке, адаптирована под личное использование: свои домены, свои ключи, минимум вопросов при установке.

---

## Что умеет

- **Установка панели и ноды** — на одном сервере или раздельно (панель на одном, нода на другом)
- **StealConfig из коробки** — при установке автоматически создаётся профиль конфигурации с инбаундом **VLESS + Reality + gRPC**:
  - `serviceName: "grpc"`, порт 443
  - `shortId` — генерируется случайно при каждой установке
  - `privateKey` — генерируется автоматически через API панели (x25519)
  - `serverNames` — подставляется домен, который вы вводите при установке
  - `dest: /dev/shm/nginx.sock` — трафик уходит в локальный веб-сервер, который отдаёт сайт-заглушку SelfSteal
- **Два веб-сервера на выбор** — nginx или Caddy
- **SelfSteal-заглушка** — автоматическая установка сайта-маскировки (случайный шаблон или свой)
- **SSL-сертификаты** — Cloudflare API или ACME, с автообновлением
- **Защита панели** — доступ по секретному URL-параметру (без него панель невидима)
- **Безопасность сервера** — UFW, блокировка приватных IP и торрентов, BBR, работа с IPv6
- **Только русский язык** — без выбора языка и лишних вопросов

## Требования

- **ОС:** Debian 11 / 12 / 13 или Ubuntu 22.04 / 24.04, свежая установка
- **Доступ:** root
- **Домены:** свой домен + поддомены (панель, страница подписок, selfsteal-домен)

---

## Быстрый старт

```bash
bash <(curl -Ls https://raw.githubusercontent.com/properr/remnawave-reverse-proxy/refs/heads/main/install_remnawave.sh)
```

Дальше скрипт сам:
1. Спросит домены (панель / подписки / selfsteal)
2. Установит Docker, nginx (или Caddy), Xray
3. Создаст панель, сгенерирует ключи и профиль **StealConfig** (GRPC)
4. Покажет логин и пароль для входа в панель

## Режимы установки

| Режим | Когда нужен |
|-------|-------------|
| **Панель + нода на одном сервере** | Компактная установка, умеренный трафик |
| **Только панель** | Центр управления без Xray |
| **Только нода** | Отдельный сервер с Xray, подключается к панели по секретному ключу |

---

## Схема работы

```
Клиент (VLESS+Reality+gRPC)
        │
        ▼
  Xray :443  ──reality──►  клиент с правильным ключом → туннель
        │
        └──fallback──►  /dev/shm/nginx.sock  →  сайт-заглушка SelfSteal
```

- Для своих клиентов нода выглядит как VPN-сервер
- Для всех остальных — как обычный сайт по HTTPS
- Reality исключает подмену: сервер сам отдаёт настоящий TLS-хендшейк

## Настройка DNS

**Один сервер (панель + нода):**

| Тип | Имя | Значение | Прокси |
|-----|-----|----------|--------|
| A | example.com | IP сервера | DNS only |
| CNAME | panel.example.com | example.com | DNS only |
| CNAME | sub.example.com | example.com | DNS only |
| CNAME | node.example.com | example.com | DNS only |

**Раздельная установка:** `node.example.com` → IP сервера ноды, остальное → IP панели.

## Обновление

Установщик умеет обновлять сам себя из этого репозитория — пункт меню «Обновление». Все модули, языковые файлы и скрипт тянутся отсюда же, так что форк остаётся автономным.

## Структура репозитория

```
install_remnawave.sh   — основной скрипт (лаунчер с меню)
src/nginx/             — модули установки для nginx
src/caddy/             — модули установки для Caddy
src/modules/           — управление панелью, нодами, Warp, IPv6
src/api/               — работа с API Remnawave (профили, ноды, хосты)
src/lang/              — языковой файл (русский)
```
